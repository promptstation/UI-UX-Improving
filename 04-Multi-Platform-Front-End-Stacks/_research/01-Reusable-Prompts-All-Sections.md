Course 04 — Multi-Platform Front-End Stacks
Task source: 00-Research-Outline-Course-04.md

You are free to install software, programs and write codes, research the internet so as to meet our goals.

---

**Section 1: Stack Cartography — Mapping 22 Ecosystems**

Task: Surveying web, desktop, and mobile stacks by language, runtime, rendering model, and distribution, building a decision matrix for choosing stacks per product need.

Absorbed skills:
- Map stacks by architecture and fit
- build selection matrices
- justify stack choices with evidence


---

**Section 2: React Ecosystem — Next.js and shadcn/ui**

Task: Next.js routing and rendering modes, server components discipline, shadcn/ui theming and composition, and production hardening for React delivery.

Absorbed skills:
- Ship Next.js apps with correct rendering choices
- theme and compose shadcn/ui
- harden for production


---

**Section 3: Vue Ecosystem — Nuxt and Nuxt UI**

Task: Nuxt architecture and modules, composable state patterns, Nuxt UI theming, and maintaining feature parity with React implementations.

Absorbed skills:
- Ship Nuxt apps idiomatically
- manage state with composables
- hold parity with sibling stacks


---

**Section 4: Desktop Frameworks — JavaFX, Avalonia and WinUI 3**

Task: XAML and FXML UI models, MVVM patterns, native packaging and auto-update per OS, and desktop-specific UX such as menus and windowing.

Absorbed skills:
- Build native-feel desktop apps in each framework
- package and update per OS
- respect desktop UX conventions


---

**Section 5: Mobile Toolkits — SwiftUI and Jetpack Compose**

Task: Declarative mobile UI on both platforms: state, navigation, lists, and platform services, plus store-readiness requirements.

Absorbed skills:
- Build equivalent features in SwiftUI and Compose
- handle platform services
- prepare store submissions


---

**Section 6: Parity Engineering — Same Design Across Stacks**

Task: Spec-driven multi-stack builds, shared design tokens, screenshot-diff testing, and change-propagation workflows keeping implementations aligned.

Absorbed skills:
- Drive multiple stacks from one spec
- enforce parity with visual tests
- propagate changes cleanly


---

**Section 7: Adapter Patterns — Shared Logic, Native Shells**

Task: Sharing API clients, validation, and business rules across stacks via codegen and packages while keeping shells idiomatically native.

Absorbed skills:
- Share logic via generated clients and packages
- keep each shell idiomatic
- version shared contracts


---

**Section 8: Capstone — One Product, Four Stacks**

Task: Full capstone: one product brief shipped on web, desktop, and both mobile platforms with proven visual and behavioral parity.

Absorbed skills:
- Deliver one product across four stacks
- evidence parity with tests
- document stack-specific decisions
