**Section 1: Agent Landscape — How Coding Agents Consume Context**

**Summary:** How Claude Code, Cursor, Windsurf, and Copilot ingest system prompts, rules files, and plugins, and what each surfaces to the model per session.

**Absorbed Skill:** Map context pipelines per agent; predict what each model sees; choose integration points deliberately.

**Section 2: Rule Authoring — Custom Instructions That Stick**

**Summary:** Writing scoped, prioritized rules: project versus global scope, positive directives over prohibitions, and negative examples that prevent known failures.

**Absorbed Skill:** Author scoped rules agents follow; prioritize without contradiction; encode failure prevention.

**Section 3: Plugin and Skill Packaging — Distributable Agent Extensions**

**Summary:** Packaging commands, references, and scripts as installable plugins or skills with manifests, versioning, and documentation.

**Absorbed Skill:** Package distributable agent extensions; version and document them; verify installation paths.

**Section 4: Sandboxing — Safe Agent Execution**

**Summary:** Permission models, filesystem and network scoping, approval gates for destructive actions, and audit logs for agent sessions.

**Absorbed Skill:** Scope agent permissions tightly; gate destructive actions; audit sessions from logs.

**Section 5: Multi-Agent Parity — Four Tools, One Standard**

**Summary:** Mapping one rule standard onto Claude Code, Cursor, Windsurf, and Copilot configs, with parity tests proving equivalent behavior.

**Absorbed Skill:** Port one standard across four agents; prove parity with tests; document per-tool gaps.

**Section 6: Evaluation — Measuring Agent Compliance**

**Summary:** Task suites measuring rule compliance, regression prompts catching drift across model updates, and scoring rubrics for agent output.

**Absorbed Skill:** Build compliance task suites; score outputs with rubrics; catch drift across updates.

**Section 7: Security Boundaries — Secrets and Prompt Injection**

**Summary:** Secret redaction from context, untrusted-content handling, indirect prompt-injection defenses, and incident response for agent misuse.

**Absorbed Skill:** Redact secrets from agent context; defend against indirect injection; respond to misuse incidents.

**Section 8: Capstone — Production Agent Integration**

**Summary:** Full capstone: rules plus plugin plus sandbox plus evals shipped for a real repo, with parity across agents and security signoff.

**Absorbed Skill:** Ship production agent integrations; evidence parity and evals; sign off security posture.
